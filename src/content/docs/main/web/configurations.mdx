这里列出关于`@malagu/web`的相关配置属性。

## malagu.session

会话配置，结构如下：

| Key          | Value            | Description |
| ------------ | ---------------- | ----------- |
| autoCommit   | true             |             |
| maxAge       | 86400000         |             |
| sessionIdKey | malagu:sessionId |             |
| sessionKey   | malagu:session   |             |

## malagu.server

服务配置，结构如下：

| Key      | Value                                  | Description |
| -------- | -------------------------------------- | ----------- |
| path     | /                                      |             |
| port     | 3000                                   |             |
| endpoint | http://localhost:${malagu.server.port} |             |

| Key           | Value             | Description |
